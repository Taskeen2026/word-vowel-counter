# Word Vowel Checker with Tkinter

## About the Project

Word Vowel Checker is a simple and interactive desktop application developed using Python and the Tkinter library. This application helps users identify vowels (A, E, I, O, U) in any word or sentence and displays the total number of vowels found.

The application provides a beautiful and user-friendly graphical interface with a light pink theme, attractive buttons, and easy-to-use input fields. Users can enter their text and click the CHECK VOWELS button to instantly see the vowels present in their input.

It also includes helpful features such as input validation, a clear button to reset the application, and an exit button to close the window.

## Features

- **Vowel Detection:** Finds vowels (A, E, I, O, U) in words and sentences.
- **Vowel Counting:** Displays the total number of vowels found.
- **Instant Results:** Shows detected vowels immediately.
- **Case Insensitive:** Detects both uppercase and lowercase vowels.
- **Input Validation:** Displays a message if the input field is empty.
- **Clear Button:** Clears the input field and previous results.
- **Exit Button:** Closes the application.
- **Beautiful GUI:** Attractive light pink and purple color theme.
- **User-Friendly Interface:** Simple and easy-to-use design.

## Technologies Used

- Python 3
- Tkinter Library
- Visual Studio Code

## How to Run the Project

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the Python file.
5. Run the following command in the terminal:

```bash
python word-vowel-counter.py
```

6. Enter any word or sentence in the input box.
7. Click the CHECK VOWELS button.
8. View the detected vowels and their total count.
